🌍 Reconhecimento

Shodan

Motor de busca para dispositivos IoT, servidores, câmeras, roteadores e serviços expostos na internet.

IoT Servidores Recon
Documentação Shodan API
Endpoint: https://api.shodan.io/shodan/host/search
Método: GET
Parâmetros:
  - query: Termo de busca
  - key: Sua chave API

Exemplo:
  GET /shodan/host/search?key=SUA_CHAVE&query=apache

Limites:
  - Free: 1 requisição/segundo
  - Resultados: Primeiras 100 páginas

Documentação oficial: https://developer.shodan.io/api

⚠️ Threat Intelligence

VirusTotal

Analise URLs, arquivos e hashes em mais de 70 antivírus simultaneamente. Detecção de malware e ameaças.

Malware Análise Scan
Documentação VirusTotal API
Endpoint: https://www.virustotal.com/api/v3
Métodos disponíveis:
  - /urls (POST): Analisar URL
  - /files (POST): Upload de arquivo
  - /analyses/{id} (GET): Obter resultado

Headers obrigatórios:
  x-apikey: SUA_CHAVE_VIRUSTOTAL

Limites:
  - Free: 500 requisições/dia
  - 4 requisições/minuto

Documentação: https://developers.virustotal.com/reference

🔍 OSINT

Have I Been Pwned

Verifique se emails, senhas ou nomes de usuário foram comprometidos em vazamentos de dados públicos.

Privacidade Vazamentos Segurança
Documentação HIBP API
Endpoints:
  - Email: https://haveibeenpwned.com/api/v3/breachedaccount/{email}
  - Senhas: https://api.pwnedpasswords.com/range/{first5Hash}

Headers:
  - hibp-api-key: SUA_CHAVE (opcional)
  - User-Agent: SeuApp/1.0

Exemplo sem chave (rate limitado):
  GET /breachedaccount/test@example.com
  Retorna: Lista de vazamentos

Para senhas (k-Anonymity):
  - Hash SHA-1 da senha
  - Enviar primeiros 5 chars
  - Comparar localmente

Documentação: https://haveibeenpwned.com/API/v3

🧪 Análise de Malware

Hybrid Analysis

Sandbox para análise comportamental de malware. Analisa arquivos executáveis em ambiente controlado.

Sandbox Malware Análise
Documentação Hybrid Analysis
Endpoint: https://www.hybrid-analysis.com/api/v2
Métodos principais:
  - /submit/url (POST): Analisar URL
  - /submit/file (POST): Upload de arquivo
  - /report/{id} (GET): Obter relatório

Headers obrigatórios:
  api-key: SUA_CHAVE
  user-agent: Falcon Sandbox
  accept: application/json

Limites:
  - Community: 10 análises/dia
  - Tamanho arquivo: 100MB

Ambientes disponíveis:
  - Windows 10 64-bit
  - Android
  - Linux

Documentação: https://www.hybrid-analysis.com/docs/api/v2

📡 Rede & Infraestrutura

BGPView

Informações de roteamento BGP, ASN, prefixos IP e dados de infraestrutura de rede global.

BGP ASN Rede
Documentação BGPView API
Endpoint: https://api.bgpview.io
Métodos gratuitos:
  - /asn/{asn} (GET): Dados do ASN
  - /ip/{ip} (GET): Dados do IP
  - /asn/{asn}/prefixes (GET): Prefixos do ASN

Exemplo:
  GET /asn/15169
  Retorna: Google LLC, IPv4: 8.8.8.0/24, etc.

Limites:
  - Rate limit: 60 requisições/minuto
  - Sem chave necessária

Documentação: https://bgpview.docs.apiary.io
