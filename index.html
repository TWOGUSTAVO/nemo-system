APIs Reais e Funcionais

Geolocalização IP

ATIVA
  • API ip-api.com gratuita
  • Mapa interativo com Leaflet
  • Informações detalhadas de localização
  • ISP, organização, timezone

WHOIS Lookup

ATIVA
  • API whois.ws pública
  • Informações de registro de domínio
  • Datas de criação e expiração
  • Nameservers e registrante

DNS Lookup

ATIVA
  • Google DNS Over HTTPS
  • Consulta de registros A, AAAA, MX
  • Resolução DNS em tempo real
  • TTL e informações técnicas

CVE Database

ATIVA
  • API CIRCL.LU gratuita
  • Banco de dados de vulnerabilidades
  • Busca por CVE ID ou produto
  • Informações CVSS e referências

Have I Been Pwned

ATIVA
  • API pública gratuita
  • Verificação de emails em breaches
  • Detalhes de violações de dados
  • Datas e descrições de vazamentos

IP Info

ATIVA
  • API ipapi.co gratuita
  • Informações detalhadas do IP
  • Localização, ISP, hostname
  • Dados de organização e ASN

AbuseIPDB

ATIVA
  • Demonstração direta do site
  • Verificação de IPs maliciosos
  • Reputação e score de abuso
  • Relatórios de atividades suspeitas

HTTP Headers

  • API httpbin.org + CORS proxy
